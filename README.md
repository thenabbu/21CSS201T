## About these files

Each paper is Markdown transcribed from the official PDF, with:

- YAML frontmatter carrying the course code, subject, session and pages transcribed
- `### Q1`, `### Q2`, … headings numbered **by position**, so the sequence is always contiguous
- LaTeX for mathematics
- marks / CO / BL annotations wherever the printed paper carried them

Answer keys are deliberately excluded — question papers only.

## Source and checking

Collected from the public SRM question-paper archive, `srmhelper.com` and `thehelpers.tech`. Every file passed a structural verifier: frontmatter present, paper non-empty, question numbering contiguous, no leaked answer lines.

Transcription is automated, so a symbol can be misread. When something looks wrong, compare against the original PDF on the SRM archive — the raw scans are not redistributed here.
