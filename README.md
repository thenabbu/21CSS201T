## About the files

Each paper is Markdown transcribed from the official PDF, with:

- YAML frontmatter: course code, course name, session, pages transcribed
- `### Q1`, `### Q2`, … headings, numbered by position so the sequence is always contiguous
- LaTeX for mathematics
- marks / CO / BL annotations where the paper printed them

Answer keys are deliberately excluded — only question papers are included.

## Source

Collected from the public SRM question-paper archive, `srmhelper.com`, and
`thehelpers.tech`. Papers were read with a vision model and checked by a
structural verifier (frontmatter present, non-empty, numbering contiguous, no
leaked answer lines); every file here passes it.

## Corrections

Transcription is automated. If a symbol is misread, open the paper's source PDF
and compare — the raw scans are not redistributed here.
